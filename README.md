## 🛠️ How to Run Locally
1. Clone this repository to your machine.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Start the engine:
   ```bash
   python bebgpt_ide/main.py
   ```
4. Access via browser at `http://localhost:8000`.
