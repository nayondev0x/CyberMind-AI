## 🛠️ Deployment & Execution
CyberMind AI is fully optimized for **Render** and local high-performance servers.

### Run Locally:
1. Clone the repository.
2. Install requirements: `pip install -r requirements.txt`
3. Start the engine: `python bebgpt_ide/main.py`

### Live on Render:
*   **Build Command:** `pip install -r requirements.txt`
*   **Start Command:** `gunicorn -w 4 -k uvicorn.workers.UvicornWorker bebgpt_ide.main:app`
